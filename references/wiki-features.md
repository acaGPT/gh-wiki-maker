# 常见 wiki 功能清单（GitHub Wiki 版）

GitHub Wiki 由 Gollum 驱动，能力远少于 MediaWiki，也少于静态站点生成器。下表按「性价比」排列：先做前五项，其余按需。

| 功能 | 支持情况 | 做法 | 建议 |
| --- | --- | --- | --- |
| `_Sidebar.md` 侧栏 | ✅ 原生 | 每行 `- [标签](页名)`，支持多级无序列表缩进 | **必做** |
| `Home.md` 首页 | ✅ 原生 | 导航地图 + 版权与编辑说明 | **必做** |
| `_Footer.md` 页脚 | ✅ 原生 | 与侧栏同语法，出现在每页底部 | **建议做**：放版权短句与年份 |
| `[[_TOC_]]` 页内目录 | ✅ 原生 | 单独一行写在 H1 之下，自动生成该页目录 | **建议做**：长页必备 |
| 锚点跳转 | ✅ 原生 | `[跳转](#章节-slug)`，slug 为标题小写去标点、空格转 `-` | 按需 |
| 术语表页 | 约定 | 单独 `Glossary.md`，各页术语首次出现处链到它 | **建议做**（中英对照尤需） |
| 变更日志页 | 约定 | `Changelog.md`，按日期倒序记改动，首页链入 | 按需 |
| 图片与署名页 | 约定 | `images/` + `Portrait-Credits.md` 记来源与授权 | 有图则**必做** |
| 双向链接索引 | 约定 | 每页末尾「相关页面」小节，人工维护 | 页面多时建议 |
| 状态标签 | 约定 | 标题后加 `_草稿 / draft_`、`<sup>Beta</sup>` | 按需 |
| 页面历史与修订对比 | ✅ 原生 | 网页端 History / Revisions，按 commit 回溯 | 无需配置 |
| 全文检索 | ✅ 原生 | 页内搜索框按标题过滤（**不检索正文**） | 认知到限制即可 |
| Mermaid 图 | ⚠️ 视平台 | ```mermaid 代码块；与仓库 Markdown 渲染能力同步演进 | 先小范围试一页 |
| 行内 HTML | ⚠️ 受限 | `<img>`、`<sup>`、`<details>` 可用；`<script>` / `<style>` 被剥离 | 谨慎依赖 |
| 数学公式 | ❌ 不支持 | 用代码块或预渲染图片 | 避免 |
| 页面级权限 | ❌ 不支持 | wiki 权限 = 仓库权限 | 无解 |
| 评论 / 讨论 | ❌ 原生无 | 可链到 Issues / Discussions | 按需外挂 |

## 推荐的最小配置

```
Home.md            首页（中英双语导航 + 版权）
_Sidebar.md        侧栏
_Footer.md         页脚（版权短句）
LICENSE            保留所有权利
Glossary.md        术语/译名对照（按需）
Changelog.md       变更日志（按需）
Portrait-Credits.md 图片署名（有图时）
images/            图片
```

## 双语站点的额外约定

1. 首页严格分两段：中文章节在前、英文章节在后，中间 `---`；
2. 正文页按**段落级**双语（中文段 + 对应英文段），不做逐句夹注，可读性更好；
3. 侧栏标签与文件名同语言（英文），首页导航条目用「英文页名 + 中文标题」双链；
4. 术语首次出现处给出中英对照并链到 `Glossary.md`，后文不再重复。
